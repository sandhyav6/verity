# Project identity and name recommendation (Phase 8)

The project is deliberately unnamed in the code, UI and README ("Prediction market simulator"): you decide the name. This is a recommendation based on what the finished product actually is.

## What the product turned out to be

A **test-token forecasting platform for Indian events**, distinguished by three things:

1. **Honest pricing:** a Solidity LMSR market maker whose maths is verified against an independent high-precision implementation, with a solvency invariant.
2. **Evidence-first resolution:** every outcome traces to hashed, publicly checkable evidence (real Open-Meteo data with provenance, or a documented official document), with a bonded challenge process, and documentation that states plainly where trust remains.
3. **Educational, not gambling:** valueless, non-transferable credits; no money anywhere.

## Naming brief

Requested on 2026-11-05: **no uncommon or hard-to-understand Sanskrit names.** Use plain English or everyday Hindi words that most people in India already say. The name should also avoid betting words such as *bet, odds, stake, win, jackpot, cash, exchange, coin*. That keeps the test-only, non-monetary positioning and the legal caution in `legal.md`. (The earlier suggestions *Anumaan*, *Pramaan*, *Sambhavana* and *Poorvanumaan* were withdrawn for that reason.)

## Recommendation: **Andaaza** (अंदाज़ा)

An everyday Hindi/Urdu word for "estimate" or "guess" ("mera andaaza hai…"), pronounced *an-DAA-za*. It means exactly what a prediction market produces, the crowd's estimate. It's short and familiar, and it isn't tied to one event type. Suggested tagline: *"The crowd's best guess, backed by evidence. Test tokens only."*

## Alternatives

| Name | Meaning | Note |
|---|---|---|
| **CrowdCast** | crowd + forecast | Instantly clear in English; a common compound, likely to clash with existing products |
| **Kal Kya?** | "what about tomorrow?" | Playful, memorable; punctuation and spacing are awkward for domains and app stores |
| **Forecast Lab India** | plain English | Signals "experiment / learning", which suits a test-token project; less catchy |
| **Pakka?** | "for sure?" (common slang) | Fun fit for "how sure is the crowd"; very informal |
| **SignalBoard** | a board of probability signals | Neutral and professional |
| **Sahi Andaaza** | "right guess" | Longer form of the recommendation; useful if the short name is taken |
| **CrowdSense** | what the crowd senses | Clear; likely to clash with existing companies |
| **Mausam & More** | "weather and more" | Leads with the most relatable markets; too narrow if economy and cricket markets grow |

## Before you adopt a name

I have **not** checked trademarks, domain names, package names or existing products using any of these names. Do that yourself, and have the legal review in `legal.md` consider the name along with the product. If you adopt a name, rename the repository, the page title in `frontend/index.html`, the header in `frontend/src/components/Layout.tsx`, the API title in `backend/app/main.py`, and the README title.
